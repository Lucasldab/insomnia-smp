# Insomnia SMP — mod pack

This is the mod pack for my Minecraft server. It's one file that lists the
mods and where to get them on Modrinth, and your launcher downloads them for
you.

**Server address:** `mc.lldab.com` · **Minecraft:** Java Edition 26.3 (Fabric)

## Join in five steps

1. **Have Minecraft Java Edition** (the PC version you log in to with a
   Microsoft account).
2. **Install the Modrinth App**: <https://modrinth.com/app>. It's free and
   handles the mods for you. (Prism Launcher works too.)
3. **Download the pack**: open
   [the latest release](https://github.com/Lucasldab/insomnia-smp/releases/latest)
   and download the `.mrpack` file.
4. **Import it**: open the Modrinth App, click **+** (create instance), choose
   **Import from file** and pick the `.mrpack` you downloaded. Wait for it to
   finish, then press **Play**.
   *Prism Launcher:* **Add Instance → Import → Browse**, pick the file, **OK**.
5. **Join**: in Minecraft go to **Multiplayer → Add Server**, type
   `mc.lldab.com` as the address, save and join.

The server is whitelisted, so send me your Minecraft username before you join
for the first time. Otherwise you'll get "You are not white-listed on this
server".

## When the pack changes

If joining says your mods or version don't match, download the newest
`.mrpack` from the releases page and import it again (step 4).

## Want a mod added?

[Open a mod request](https://github.com/Lucasldab/insomnia-smp/issues/new?template=mod-request.yml)
and paste the mod's Modrinth page (you need a free GitHub account). Within a
minute a bot replies saying whether the mod has a version for this server, and
then I decide whether to add it. You can also just send me the link.
